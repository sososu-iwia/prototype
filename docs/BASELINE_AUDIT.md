# Исходный baseline — 19 октября 2026

Аудит выполнен непосредственно по исходникам. В папке нет `.git` и исходного package.json/сборки. ZIP отсутствует. Публичный референс `https://kemelordabasy-fc.netlify.app/` и `/team.html` не удалось получить через web-инструмент (Internal Error). Поэтому визуальная основа — **локальный исходный сайт**, не выдуманные снимки Netlify.

Скрипт `scripts/baseline.mjs` запустил реальный headless Chrome (Playwright) против Python static HTTP server. Сняты главная, about, team, matches на 1440/768/390 px при высоте 1000. Перед полным снимком пройдены scroll reveal-секции. Снимки в `docs/baseline/`, первоначальный журнал ошибок `errors.json`. macOS нечувствителен к регистру файлов, поэтому несовпадение MP4 на этой машине само по себе не даёт 404; ошибка установлена сравнением точных путей, важна для Linux.

## Найденные дефекты

- `css/style.css`: 5342 строки; `js/script.js`: 3555; `matches.html`: 3020, включая отдельные inline styles/scripts. Повторная реализация header/footer, переключения языка и данных.
- Исходная страница news пуста, но все страницы ссылаются на неё.
- Карточки игроков не имеют профильного URL, содержат только имя/номер/позицию. Нет подтверждённых дат рождения, роста, статистики: не заполнены случайными значениями.
- `images/gallery1.MP4` против `images/gallery1.mp4` в HTML. Все новые пути консистентно lowercase.
- 34 изображения: **327 404 236 bytes**; MP4: **19 972 340 bytes**. Крупные оригиналы игроков 7008×3944. Нет responsive variants/lazy/intrinsic sizing. Видео запускалось сразу без poster/visibility policy.
- Соперник `yelimai` в массиве матчей не совпадает с `yelimay` в словаре. Импорт исправляет FK, исходный файл сохранён.
- Netlify functions дублируют provider; league=389/season=2026 зашиты, нет timeout/retry/валидации/last-success fallback. Старые реализации архивированы в `legacy/netlify`; совместимые endpoint теперь только bridge к API.
- Footer social/video ссылки `href="#"` не являются подтверждёнными адресами. Они не перенесены как кликабельная навигация.
- Manrope указан в CSS, но не загружается. Нет гарантии казахских glyphs. Теперь локальный Noto Sans с OFL и реальной проверкой всех букв Ә Ғ Қ Ң Ө Ұ Ү Һ І.
- Scroll-обработчики и DOM textContent для переводов; языковые aria-label/alt неполные. Теперь next-intl namespaces, locale-prefix и cookie.
- Ряд исходных цветов не проходит WCAG AA. Исправлена яркость текста/кнопок в пределах navy/голубой палитры.
- Обработчики только мыши, недостаточный focus management. Новый lightbox — native modal dialog, карточки — обычные ссылки.
- 2000 как «год основания», история 1960-х, счётчик фанатов и текущие результаты нельзя считать установленными фактами. Сохранён архив с provenance, числовые утверждения без источников не выдаются за проверенные.

## Визуальная основа

Исходные navy `#020b1c` / `#041f45`, акцент `#38bdf8`, поверхности `#f8fafc`, ink `#0f172a`, контейнер 90%/1300px, hero-фон и его градиенты, широкие отступы, стеклянная match-card, радиусы, сетки и фотографии сохранены. Оригинальные responsive breakpoints 1100/950/900/850/650/600 дополнены исправлениями переполнений. Noto Sans и контраст — изменения по требованиям типографики/доступности. Нового UI kit, Tailwind, тяжёлой аналитики или Академии нет.

Автоматический pixel-perfect порог не заявлен: содержание next match/новостей, шрифт и достоверность счётчиков закономерно изменились. Снимки после миграции в `docs/verification/`; hero сравнивался с локальным оригиналом. Основные формы, галерея, мобильная навигация проверяются E2E.

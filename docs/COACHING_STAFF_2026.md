## Продолжение после QA

Новых тренеров в этом продолжении не создано. Сохранены три PUBLISHED/VERIFIED тренера KFF и три DRAFT сотрудника клуба; роли и фотографии черновиков не подтверждались автоматически.

В Staff CMS добавлен просмотр «История сотрудника» для каждой строки: номер версии, сохранённая должность и роль, команда, сезон, публикационный статус, источник и время сохранения. API возвращает названия команды и сезона. В интерфейсе явно указано, что время сохранения версии не является датой трудового договора. История загружается при открытии; ошибки имеют повторный запрос. Создание, редактирование и мягкое архивирование проверяются через реальные формы Chrome на временном сотруднике, без изменения шести основных записей.

Поиск Staff CMS исправлен: он учитывает локализованные имена и источник вместо поиска только по техническому ID. Интеграционная проверка дополнительно подтверждает поиск созданного сотрудника и названия команды/сезона в истории после перезапуска API.

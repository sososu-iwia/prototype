# FC Ordabasy — финальная локальная приёмка

Дата: 30 октября 2026. Ветка: `codex/premium-redesign-20261030`. Проверяемый код приложения: `f5d0e53`.

Этот отчёт относится к проверкам после `d4f7314`. Результаты предыдущего редизайна и октябрьского hardening остаются историческими. Публичный deployment не выполнен.

## A. Что реализовано

Сохранены Next.js, NestJS, Prisma, PostgreSQL, авторизация, CMS, архив и визуальный стиль. Выполнена дополнительная приёмка существующего редизайна: исправлены поиск новых CMS-сущностей, проверка резервных копий, обработка повреждённого CSRF, воспроизведение галереи и отступы внутренних страниц. Добавлены воспроизводимые проверки полного просмотра и настоящей навигации на пяти ширинах.

## B. Обнаруженные ошибки

Найдены один P0 в обработке повреждённого CSRF и несколько P1: неполная проверка backup, поиск CMS только по ID, гонки видео, лишние отступы и пустые ячейки галереи. Расширенный прогон дополнительно выявил нестабильный переход в админке при продолжающейся плавной прокрутке и недостигнутый Lighthouse gate. Ниже разделены исправления и оставшееся ограничение производительности.

Маршруты: главная, about, honours, архивный team, три team-pages, players, профиль Бекхана Шайзады, matches, statistics, standings, news, статья website-archive, gallery, academy, admission, partners и privacy. Проверяются KZ/RU/EN и ширины 390/768/1024/1440/1920. Перед full-page capture выполняется прокрутка до footer и ожидание изображений. Сохраняются ошибки Console/Network, overflow, сломанные изображения и обрезанные заголовки.

После последней production-сборки в нативном Google Chrome вручную прокручены главная KZ и поступление RU от hero до footer; открыты партнёры KZ/RU и поступление EN. Проверены переход из footer через Club → Partners и смена языка с сохранением маршрута. Затем визуально просмотрены все последовательные фрагменты всех 19 целей KZ на 390/1440 px: 23 контактных листа. Ещё 9 листов охватывают главную на 768/1024/1920, RU mobile / EN desktop, академию RU, поступление EN и прежние before-снимки. Формы сохранения CMS просмотрены на всех трёх языках. Это просмотр Codex, не независимая человеческая приёмка.

Автоматизированный финальный Chrome-проход: **285 views, 171 route/section PNG, issues `[]`**. На всех пяти ширинах пройдены **300 настоящих переходов меню** с normal motion; ещё **3 CMS save/reload/logout сценария** — всего **303/303**, errors `[]`. ## H. Производительность

Lighthouse 13.5.0, стандартная mobile-симуляция, новый Chrome profile на каждый замер, три холодных замера на маршрут. Условия и протокол не подменяются. JSON каждого измерения, первый trace и DevTools network log сохраняются. Строгий gate остаётся включён: LCP <2500 ms, Performance ≥90, CLS ≤0.1, Accessibility/SEO ≥95.

Предварительный анализ определил LCP главной как `img.editorial-hero-image`; это исходная фотография в responsive AVIF, eager/high priority. Проверены waterfall, Noto font preload/swap, блокирующие стили, React/Next chunks, SSR/API. Эксперимент Next `inlineCss` ухудшил предварительный результат до Performance 85 / LCP 3.307 s и **откачен**. Контент, анимации, security middleware и пороги не отключались ради оценки.

Финальная серия на `f5d0e53`: **54 холодных замера, 18 маршрутов × 3; exit code 1**. Медиана Performance ниже 90 на четырёх маршрутах: team, second-league, players и gallery. LCP median не проходит строгую цель <2.5 s на 16 из 18. Accessibility по всем 54 замерам минимум 96, SEO минимум 100, максимальный CLS 0.00131548. Это **не пройденный release gate**.

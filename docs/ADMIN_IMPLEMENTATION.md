## Границы production-проверки

Docker daemon на данном компьютере не запущен: Compose syntax/config проверяются, контейнерная сборка и VPS/TLS не объявляются проверенными. Реальный приватный S3 bucket, IAM credentials и домен не предоставлены; код и конфигурация готовы, подключение/DR у выбранного провайдера остаётся эксплуатационным шагом. API-Football остаётся optional, текущие спортивные факты требуют проверки клубным редактором. Постоянный пользователь с реальным паролем автоматически не создавался: используйте безопасный bootstrap.

Перед релизом: создать SUPER_ADMIN, настроить PostgreSQL/S3/HTTPS/секреты, сделать backup, просмотреть и применить миграции, перенести прежние local uploads, проверить реальные изображения и выполненный recovery drill в отдельной инфраструктуре.

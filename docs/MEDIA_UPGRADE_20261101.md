# FC Ordabasy — партнёры, hero и видео

Дата приёмки: 1 ноября 2026 (Asia/Almaty). Ветка `codex/premium-redesign-20261030`. Изменения ограничены тремя элементами; API, схема PostgreSQL, публикационные правила, навигация и остальные разделы сохранены.

## Лента партнёров

`SponsorGrid` использует общий `SponsorMarquee`. Ноль записей даёт существующее сообщение, одна — статичную карточку, две и более — ленту. Публичные данные по-прежнему приходят из `/api/v1/sponsors`: `PUBLISHED`, `logoApproved`, `verifiedAt`, источник и validity dates проверяются существующим backend. Порядок задаёт CMS.

Две одинаковые половины содержат целое число наборов. `ResizeObserver` измеряет ширину набора вместе с последним gap; число повторов заполняет контейнер и обеспечивает умеренную длительность. Смещение равно точной ширине одной половины; скорость — 52 CSS px/s. DOM не растёт со временем. Дубли скрыты от accessibility tree, inert и не содержат ссылок. Hover/focus ставят движение на паузу. Кнопка остановки и reduced motion дают статичный горизонтально прокручиваемый набор без дублей. Логотипы используют светлые карточки и contain.

В существующем разделе Sponsors добавлен закрытый preview. Он читает сохранённые логотипы через защищённый Admin API, включает черновики, исключает архив и группирует одинаковые файловые URL. Надпись явно сообщает, что это внутренний просмотр, а не список подтверждённых партнёров. Никаких записей или publication flags preview не меняет. Одинаковое изображение, загруженное под другим URL, остаётся отдельным сохранённым файлом.

Публично подтверждён **один Bank RBK**, поэтому итоговый сайт намеренно показывает статичную карточку. Eurasia, Integra Construction, ERG, SCAT Airlines, Global Coffee и City Hotel остаются неподтверждёнными DRAFT. Наличие файла не считается подтверждением партнёрства. Молодёжные разделы не получают новых спонсоров.

## Hero

Оригинал — `images/hero.jpg`, **1600×994**, 260246 bytes. SHA-256: `ae92147b9bbf3c0c84cea276109ff3d8a93f78feac0366bc3e6db73ed3a6553d`. Более крупный оригинал той же фотографии в переданных файлах не найден. Фотография и тексты сохранены, upscaling не выполнялся.

Новый воспроизводимый генератор создаёт AVIF quality 64 / WebP quality 90:

- Полная фотография: 640, 960, 1280 и 1600 px.
- Мобильный crop из оригинала: 820×994, left 499 / top 0; варианты 400, 640 и 820 px. Фокус 64% сохраняет существующее кадрирование футболистов.

На телефоне прежний полный 640 px кадр растягивался по высоте и терял детали в узком видимом фрагменте. Теперь браузер получает файл с нужным мобильным фрагментом. Shared srcSet/sizes используются и picture, и preload. Удалён устаревший HTTP preload главной из `proxy.ts`, который параллельно запрашивал старое изображение. Учитывается cover scaling, сохранены eager/high priority, палитра, overlay и композиция. Исправлена intrinsic height с 1067 на фактическую 994.

AVIF: desktop 1600 — 87032 bytes; mobile 640 — 38006, mobile 820 — 50570. Исходный JPEG не раздаётся как LCP-ресурс. Для дальнейшего улучшения на большом Retina-экране нужен новый оригинал примерно **4000×2500 или больше**: новые настройки сжатия не восстанавливают отсутствующие детали.

Генератор: `node scripts/build-editorial-hero.mjs`, также включён в `npm run media:build`. Старые assets и девять оригиналов design package сохранены.

## Видео

Общий `GalleryVideo` использует существующую полную delivery-копию H.264 High / yuv420p / faststart, **960×720, 30 fps, 24.066667 s, 6153816 bytes**, без аудиодорожки. Оригинальный MP4 не изменён.

`autoPlay`, `muted`, `loop`, `playsInline` работают вместе с viewport observer. Src главной подключается при появлении видео; постер отдельной галереи остаётся доступным в SSR. При уходе из viewport/вкладки — пауза, при возвращении — продолжение с того же времени. Явная пауза пользователя запоминается. Reduced motion блокирует автоматический старт, но разрешает ручной Play. Rejection play() даёт локализованный fallback и кнопку повтора; штатный AbortError при смене состояния не показывается как ошибка. Native controls и fullscreen сохранены. Подписи передаются с сервера, без зависимости публичной галереи от клиентского Intl provider.

**Ограничение исходника:** полностью незаметного визуального стыка нет. Внутри MP4 присутствуют тёмные заставки с эмблемой: примерно 13,767–14,800 с и 22,467–24,067 с. `blackdetect` классифицирует их как почти чёрные; ручной просмотр кадров подтверждает эмблему, поэтому это содержимое нарезки, а не пустые кадры или ошибка плеера. Файл сохранён целиком. Нативный loop возвращается с 24,033 с к 0 без дополнительной загрузки или ошибки; однако заключительная тёмная заставка видна перед возвратом к началу. Для визуально seamless-версии предлагается отдельная веб-копия: перенести заключительную эмблему в overlay и соединить последнюю сцену с первой коротким crossfade, сохранив обе сцены и оригинал. Такой монтаж здесь не выполнен.

[Контактный лист исходных кадров](verification/media-20261101/screenshots/video-source-dark-cards.png): слева направо, сверху вниз — 13,633 / 14,000 / 14,800 / 21,000 / 21,667 / 22,000 / 22,333 / 23,000 с.

## Продолжение: сокращение CSS и гидратации

Коммит `300e193` удаляет устаревшие селекторы старого макета, выносит Admin CSS из публичной загрузки и позволяет Next объединить публичные стили в один chunk. Галерея формирует изображения/подписи на сервере; браузер получает небольшой opener и lightbox по запросу, без медиаманифеста для гидратации галереи. Только первое видео отдельной галереи получает `preload="metadata"`; видео главной сохраняет отложенное подключение, viewport/tab/reduced-motion/ручную паузу и обработку отказа autoplay. `preload` остаётся подсказкой браузеру ([HTML Standard](https://html.spec.whatwg.org/multipage/media.html#attr-media-preload)). Hero, фотографии и видеобайлы не изменены.

Сопоставимые серии по три холодных профиля (стандартные mobile throttling и пороги сохранены):

| Серия | Главная: Performance / медиана LCP | Галерея: Performance / медиана LCP |
| --- | --- | --- |
| Новый контроль d117af4 | 95 / 2.914 s (2.905–3.001) | 90 / 3.559 s (3.505–3.596) |
| Разделение CSS | 96 / 2.852 s (2.848–2.914) | 92 / 3.366 s (3.344–3.462) |
| SSR галереи + один публичный CSS | 96 / 2.851 s (2.844–2.971) | 92 / 3.364 s (3.350–3.412) |

В последней из этих серий CSS transfer снизился с 20,886 до 14,294 байт (2 → 1 запрос), JavaScript главной — с 151,121 до 149,150 байт. Удаление клиентского медиаманифеста уменьшило JS, но самостоятельный дополнительный выигрыш LCP от SSR/metadata не подтверждён. Результаты не выдаются за достижение строгого LCP <2.5 s.

Дополнительно проверен и **откачен** эксперимент с 720 px вариантами трёх фотографий при прежних AVIF/WebP quality: главная продолжала выбирать 960 px из-за `sizes="100vw"` (412 × DPR 1.75 = 721). Медиана главной 2.846 s не дала значимого выигрыша относительно контрольной серии. Для дальнейшего уменьшения этой группы необходимы корректные `sizes` с учётом `object-fit: cover`, без принудительного выбора изображения ниже требуемого физического разрешения. Hero SHA проверен неизменным; экспериментальные шесть файлов удалены, manifest полностью восстановлен к проверенному коммиту. Неудачная/непринятая серия сохранена в локальных артефактах.

Финальная серия 18 × 3, её медианы/диапазоны, оставшиеся превышения LCP и CI окончательного SHA приведены в описании [Draft PR #4](https://github.com/sososu-iwia/prototype/pull/4). Сырые JSON, trace, waterfall и журнал отката — `docs/verification/continuation-20261101/`. Функции, качество Hero и настройки Lighthouse не отключались и не ослаблялись ради оценки.
